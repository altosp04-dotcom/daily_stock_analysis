## 1. 研究背景与动机

### 1.1 工程问题

天然气长输管网中，压缩机站是能耗最密集的环节，约占管网总运营成本的 30%–50%。精确的压缩机模型是管网调度优化的基础。现有建模方法面临三个核心矛盾：

| 矛盾 | 纯数据驱动方法（DDM） | 纯物理方法（机理模型） |
|------|----------------------|----------------------|
| 数据覆盖不足时的外推能力 | ❌ 外推失效 | ✅ 有保障 |
| 设备退化后的自适应能力 | ✅ 可通过再训练更新 | ❌ 需重新标定 |
| 工况边界外的泛化性 | ❌ 分布外失效 | ✅（若物理模型准确） |
| 小样本精度 | ❌ | ✅ |

**核心科学问题**：如何在 SCADA 历史数据稀疏、特性曲线随运行时长退化的双重约束下，构建一个兼顾物理一致性和数据拟合精度、并具备不确定性量化能力的压缩机模型？

### 1.2 文献综述中的研究缺口（Research Gap）

- **缺口 G1**：现有 PINN 在压缩机领域的应用多假设特性曲线准确，忽视了曲线本身的时变退化（老化、积垢、叶片磨损等）；
- **缺口 G2**：相似律（Fan Law / Affinity Laws）在大偏差转速比下的适用范围未经严格验证，且缺乏不确定性传播分析；
- **缺口 G3**：真实数据与物理生成数据的混合比例（mixing ratio）通常凭经验给定，缺乏理论最优准则；
- **缺口 G4**：现有研究很少将物理信息压缩机模型嵌入实时管网优化求解器，验证端到端的工程价值。

## 2. 现有方案的致命缺陷分析

> 以下批评直指可能导致**顶刊拒稿**的核心问题，请认真对待。

### 2.1 原创性严重不足（致命）

**问题描述**：将特性曲线作为物理软约束嵌入神经网络，本质上是 Physics-Informed Neural Networks（Raissi et al., 2019）的直接套用。如果仅将压缩机特性曲线替换为损失函数中的正则项，而没有解决特性曲线本身随时间退化的问题，本文与已有文献的边际差异几乎为零，**无法通过二区以上期刊的审稿**。

**改进方向**：
- 核心创新必须落在"**特性曲线退化的在线检测与自适应修正**"而非仅仅"使用特性曲线作为约束"；
- 需提出数学上可证明收敛的退化估计算法，而非凭经验调参。

### 2.2 方法论跳跃（严重）

**问题描述**：提案中"基于相似律，或者提出一种新的方法"的表述暴露了方法论基础不牢固。相似律（Affinity Laws）在转速偏差超过±20% 时会引入不可忽视的误差（文献表明误差可达 5%–15%），且对温度、气体组分变化不敏感。若直接使用，审稿人会质疑物理基础的有效性。

**改进方向**：
- 推导基于无量纲数（马赫数、雷诺数、比速）的广义相似律，量化其适用范围；
- 对超出适用范围的工况，提出残差补偿项（见第4.2节）。

### 2.3 数据合成比例无理论依据（较严重）

**问题描述**："真实数据占几成，生成的数据占几成"是一个核心设计决策，若仅凭试验确定，审稿人会要求理论支撑。随机插值或简单拼接的合成数据可能引入分布偏移，导致模型在真实工况边界处性能下降。

**改进方向**：
- 采用信息几何框架（KL散度最小化）或主动学习准则确定最优混合比；
- 或采用条件生成对抗网络（CGAN）在物理约束下生成高保真合成样本。

### 2.4 缺乏不确定性量化（较严重）

**问题描述**：用于管网优化的模型若没有预测置信区间，调度系统无法进行风险评估，工程价值大打折扣，且难以区分模型认知不确定性（epistemic）和随机不确定性（aleatoric）。

**改进方向**：
- 引入贝叶斯神经网络或 Monte Carlo Dropout，输出预测分布而非点估计。

### 2.5 消融实验设计缺失（致命）

**问题描述**：提案未列出任何 Baseline。若没有清晰的消融实验，审稿人无法判断各模块（物理约束、退化修正、合成数据）对最终性能提升的具体贡献，直接拒稿风险极高。

## 4. 详细研究方案

### 4.1 数据准备与质量控制

#### 4.1.1 SCADA 数据预处理

**变量选择**（最少变量集，避免维度灾难）：

| 变量 | 符号 | 单位 | 备注 |
|------|------|------|------|
| 进口压力 | P₁ | MPa | 压缩机进口表压 |
| 出口压力 | P₂ | MPa | 压缩机出口表压 |
| 进口温度 | T₁ | K | |
| 转速 | N | rpm | |
| 流量 | Q | m³/h（标况）| 超声波流量计 |
| 功率（轴功率） | W | kW | 由电流/扭矩计算 |
| 气体组分 | Z | — | 压缩因子，月均值 |

**质量控制流程**：
1. **传感器漂移检测**：对每个传感器信号计算 14 天滚动均值±3σ 控制图，标记异常点；
2. **物理约束过滤**：删除违反以下硬约束的记录：
   - P₂/P₁ < 1（压缩比不合法）
   - 等熵效率 η < 0.2 或 η > 0.95（明显仪表故障）
   - Q < Q_surge（喘振工况，需单独建模）
3. **缺失值处理**：对缺失率 <5% 的变量用线性插值；>5% 的片段整段删除，记录删除比例；
4. **稳态识别**：采用滑动窗口方差检验，仅保留稳态片段（σ/μ < 2%，窗口长度 5 分钟）用于训练，瞬态数据单独分析。

#### 4.1.2 数据覆盖分析（针对外推失效问题）

绘制 (Q, N) 和 (Q, P₂/P₁) 二维工况密度图，量化 SCADA 历史数据的工况覆盖率：

```
覆盖率 = 历史数据覆盖工况空间面积 / 设计工况空间总面积
```

明确标注数据稀疏区域（这是后续物理约束必要性的重要动机，需在论文中量化呈现）。

### 4.2 压缩机特性曲线退化建模（核心创新 C1）

#### 4.2.1 特性曲线的参数化表达

原始特性曲线（额定转速 N₀）拟合为二次多项式：

```
H₀(Q) = a₀ + a₁Q + a₂Q²        (扬程-流量特性)
η₀(Q) = b₀ + b₁Q + b₂Q²        (效率-流量特性)
```

退化后的特性曲线引入**退化参数向量** **θ** = (δa₀, δa₁, δa₂, δη_max, t_deg)：

```
H*(Q, t; θ) = (a₀+δa₀(t)) + (a₁+δa₁(t))Q + (a₂+δa₂(t))Q²
```

其中退化随时间演化遵循：

```
dδaᵢ/dt = -κᵢ · δaᵢ + νᵢ(t)    (一阶线性退化 + 随机扰动)
```

κᵢ 为退化速率，νᵢ(t) 为维纳过程噪声。

#### 4.2.2 在线退化参数估计

采用**扩展卡尔曼滤波（EKF）**或**粒子滤波（PF）**对退化参数进行在线估计：

**状态空间模型**：
```
状态方程: θ(k+1) = f(θ(k)) + w(k),  w ~ N(0, Q_w)
观测方程: y(k) = H*(Q(k), t; θ(k)) + v(k),  v ~ N(0, R_v)
```

**算法流程**：
1. 预测步骤：利用退化演化方程预测下一时刻退化参数；
2. 更新步骤：利用实时 SCADA 测量值（P₂/P₁ 等）更新退化参数估计；
3. 退化预警：当 ||δθ(t)||₂ > τ_alarm 时，触发特性曲线更新。

**关键研究问题**：EKF 与 PF 在非线性退化场景下的估计误差对比——这可作为一个独立的子贡献。

#### 4.2.3 广义相似律的有效范围验证

标准相似律：
```
Q/Q₀ = N/N₀
H/H₀ = (N/N₀)²
W/W₀ = (N/N₀)³
```

**验证实验**：利用不同转速下的历史数据，计算相似律预测值与实测值的偏差，绘制"转速偏差 vs. 相似律误差"曲线，明确相似律的适用范围（预期：N/N₀ ∈ [0.8, 1.2] 内误差 <3%，超出则显著增大）。

对超出适用范围的工况，引入**修正函数**：
```
H_corrected(Q, N) = H₀(Q·N₀/N)·(N/N₀)² · Φ(Ma, Re)
```

其中 Φ(Ma, Re) 为基于马赫数和雷诺数的二维修正因子，通过回归拟合确定。

### 4.3 贝叶斯物理信息神经网络（B-PINN）框架（核心创新 C3）

#### 4.3.1 网络架构

采用**精简架构**（满足"尽量使用少的神经元数量"的要求），同时兼顾表达能力：

```
输入层: x = [Q, N, T₁, P₁, Z]  (5维)
     │
     ▼
隐藏层 1: 32 神经元, Swish 激活
     │
     ▼
隐藏层 2: 32 神经元, Swish 激活  
     │
     ▼
分叉输出:
  ├─ 均值输出: [P₂, W, η]  (3维)
  └─ 对数方差输出: [log σ²_P₂, log σ²_W, log σ²_η]  (3维)
```

**参数量估算**：5×32 + 32×32 + 32×6 = 160 + 1024 + 192 = 1376 个参数，极为精简。

#### 4.3.2 损失函数设计

总损失函数：

```
L_total = L_data + α·L_physics + β·L_KL + γ·L_monotone
```

**（1）数据拟合损失（负对数似然）**：
```
L_data = Σᵢ [log σ²(xᵢ) + (yᵢ - ŷ(xᵢ))²/σ²(xᵢ)]
```
使用异方差高斯似然，自动学习各工况点的预测不确定性。

**（2）物理约束损失**：
```
L_physics = ||ŷ(Q, N) - H*(Q,N; θ̂)||²   (特性曲线软约束)
           + ||η̂(Q) - η*(Q; θ̂)||²         (效率约束)
           + λ_energy · ||W_predicted - W_thermo||²  (热力学能量守恒)
```
其中热力学功率：
```
W_thermo = Q · ρ · Δh_isentropic / η_isentropic
```

**（3）KL 散度正则项（贝叶斯先验）**：
```
L_KL = KL[q(w; φ) || p(w)]
```
采用均值场变分推断（MFVI），将权重 w 建模为独立高斯分布，先验 p(w) = N(0, σ²_prior)。

**（4）单调性约束（物理先验）**：
```
L_monotone = Σⱼ max(0, ∂ŷ_H/∂Q)²   (扬程随流量单调递减)
```
通过软惩罚强制满足压缩机特性的单调性。

**权重自适应调整**：采用 GradNorm 算法（Chen et al., 2018）在训练过程中自动平衡 α, β, γ，避免人工调参。

#### 4.3.3 训练策略

- **两阶段训练**：
  1. **预训练阶段**：仅用物理生成数据训练，初始化网络权重接近物理模型（α=1, β=0.01, γ=1）；
  2. **微调阶段**：加入真实 SCADA 数据，逐步增大 β，使模型向数据分布靠近（Curriculum Learning）。

- **优化器**：Adam + 余弦退火学习率调度，初始 lr=1e-3，最小 lr=1e-5。

- **在线更新**：当退化检测模块（C1）触发更新时，仅对最后两层权重进行微调（冻结前层），降低灾难性遗忘风险。

### 4.4 物理约束数据合成框架（PCS-DataGen，核心创新 C2）

#### 4.4.1 虚拟工况点生成

基于修正后的特性曲线 H*(Q, N; θ̂)，利用扩展相似律生成虚拟工况点：

1. 在 (Q_min, Q_max) 范围内均匀采样流量 Q_syn；
2. 在有效转速范围 (N_min, N_max) 内均匀采样转速 N_syn（避开喘振边界）；
3. 计算对应的 P₂_syn、W_syn、η_syn；
4. **物理可行性过滤**：删除违反热力学约束的合成样本（P₂_syn < P₁, η_syn < 0 等）。

#### 4.4.2 最优混合比确定（理论推导）

**命题**：设真实数据分布为 P_real，合成数据分布为 P_syn，混合分布为：
```
P_mix(λ) = λ·P_real + (1-λ)·P_syn,  λ ∈ [0,1]
```

最优混合比 λ* 通过最小化模型在真实数据上的泛化误差上界确定：

```
λ* = argmin_λ { E[L_data(P_mix(λ))] + C · KL(P_mix(λ) || P_test) }
```

其中 C 为正则化常数，P_test 为测试集分布。

**实践近似**：通过交叉验证（5-fold CV）在 λ ∈ {0.3, 0.4, 0.5, 0.6, 0.7, 0.8, 0.9} 上搜索最优 λ*，并绘制"λ vs. 验证集 MSE"曲线。

**预期假设**：λ* ≈ 0.6–0.7（真实数据占 60%–70%），这一比例会随历史数据量增加而增大（即数据越少，合成数据越重要）。

#### 4.4.3 分布对齐验证

用最大均值差异（MMD）检验合成数据与真实数据的分布差异：
```
MMD²(P_real, P_syn) = E[k(x,x')] - 2E[k(x,y)] + E[k(y,y')]
```
若 MMD² < ε_threshold，则认为分布对齐良好。

| 指标 | 公式 | 说明 |
|------|------|------|
| MAE | 1/N·Σ|yᵢ-ŷᵢ| | 平均绝对误差 |
| RMSE | √(1/N·Σ(yᵢ-ŷᵢ)²) | 均方根误差 |
| MAPE | 1/N·Σ|yᵢ-ŷᵢ|/|yᵢ| | 平均绝对百分比误差 |
| NLL | -Σlog p(yᵢ\|xᵢ) | 负对数似然（评估不确定性质量）|
| PICP | P(yᵢ ∈ CI₉₅%) | 95%置信区间覆盖率（应≈0.95）|
| 外推误差 | 在数据稀疏区域的 RMSE | 评估外推能力 |

### 4.6 管网运行优化应用

#### 4.6.1 优化问题建模

以江津压气站为例，单站多机优化问题：

```
目标函数:
min Σₖ Wₖ(Qₖ, Nₖ)          (最小化总功耗)

约束条件:
Σₖ Qₖ = Q_demand             (流量需求满足)
P₂_min ≤ P₂ₖ ≤ P₂_max       (出口压力范围)
Nₖ_min ≤ Nₖ ≤ Nₖ_max        (转速范围)
Qₖ > Q_surge(Nₖ)             (防喘振约束)
ŷₖ ~ B-PINN(Qₖ, Nₖ, ...)    (B-PINN预测模型)
```

#### 4.6.2 鲁棒优化（考虑不确定性）

利用 B-PINN 输出的预测方差，构建均值-方差鲁棒优化：

```
min E[W_total] + γ · √Var[W_total]
```

其中γ为风险厌恶系数（由调度员设定），这使得优化结果在模型不确定性高时自动趋于保守。

#### 4.6.3 优化求解方法

- **内层**：Sequential Quadratic Programming（SQP）+ B-PINN 作为黑盒模型（自动微分提供梯度）；
- **外层（多机组合）**：粒子群优化（PSO）或差分进化（DE）作为全局搜索；
- **实时性要求**：单次优化求解时间 <10 秒（管网调度周期通常为 5–15 分钟）。

**评估指标**：
- 与现有调度方案对比的节能率（%）
- 约束违反率（%)
- 优化求解成功率（%）

## 5. 数学推导

### 5.1 B-PINN 的变分推断框架

设神经网络权重 w 的后验分布为 q(w; φ)，先验为 p(w)，观测数据为 D = {(xᵢ, yᵢ)}。

**证据下界（ELBO）**：
```
log p(D) ≥ E_q[log p(D|w)] - KL[q(w;φ) || p(w)]
         = -L_NLL - L_KL  ≡ -L_ELBO
```

物理约束通过修改似然函数引入：
```
log p(D|w) = log p_data(D|w) + α · log p_physics(w)
```

其中物理约束似然：
```
p_physics(w) ∝ exp(-||H_NN(Q,N;w) - H*(Q,N;θ̂)||² / (2σ²_phys))
```

这使得网络的预测在物理曲线已知的区域具有较小方差，在稀疏区域自动增大方差（由 L_NLL 中的 σ² 项自动学习）。

### 5.2 退化参数可辨识性分析

**定理（可辨识条件）**：若压缩机在运行期间工况点覆盖至少 3 个不同流量水平，则退化参数 θ = (δa₀, δa₁, δa₂) 可辨识（在噪声方差 σ² 已知的条件下）。

**证明思路**：
- 观测方程 y_j = a₀+δa₀ + (a₁+δa₁)Q_j + (a₂+δa₂)Q_j² + ε_j 构成线性系统；
- 当 3 个工况点 Q_j 不共线时，观测矩阵满秩，δa 可唯一确定。■

**工程含义**：压缩机在日常运行中工况点通常远多于 3 个，可辨识性条件天然满足；但若长时间在单一工况点运行（如定频运行），退化参数不可辨识，算法应退化为定期离线标定模式。

## 附录 B：特性曲线拟合示例代码

```python
import numpy as np
from scipy.optimize import curve_fit

def characteristic_curve(Q, a0, a1, a2):
    """压缩机扬程-流量特性曲线（二次多项式）"""
    return a0 + a1 * Q + a2 * Q**2

def fit_characteristic_curve(Q_data, H_data, Q_range=None):
    """
    拟合压缩机特性曲线
    
    Parameters
    ----------
    Q_data : array-like, 流量测量值 [m³/h]
    H_data : array-like, 扬程/压比测量值
    Q_range : tuple, (Q_min, Q_max) 有效流量范围（过滤喘振和堵塞工况）
    
    Returns
    -------
    params : array, 拟合系数 [a0, a1, a2]
    covariance : array, 参数协方差矩阵（用于不确定性传播）
    """
    Q_data = np.asarray(Q_data)
    H_data = np.asarray(H_data)
    
    if Q_range is not None:
        mask = (Q_data >= Q_range[0]) & (Q_data <= Q_range[1])
        Q_data, H_data = Q_data[mask], H_data[mask]
    
    # 初始参数估计（避免收敛到局部最优）
    if len(Q_data) < 3:
        raise ValueError("需要至少3个数据点才能拟合特性曲线")
    if np.ptp(Q_data) == 0:
        raise ValueError("Q_data 无变化量（所有流量值相同），无法拟合特性曲线")
    p0 = [H_data.max(), -np.ptp(H_data) / np.ptp(Q_data), 0.0]
    
    params, covariance = curve_fit(
        characteristic_curve, Q_data, H_data,
        p0=p0,
        bounds=([0, -np.inf, -np.inf], [np.inf, 0, 0]),  # a0>0, a1<0, a2<0（单调递减）
        maxfev=10000
    )
    
    # 拟合优度
    H_pred = characteristic_curve(Q_data, *params)
    ss_res = np.sum((H_data - H_pred) ** 2)
    ss_tot = np.sum((H_data - H_data.mean()) ** 2)
    r_squared = 1 - ss_res / ss_tot
    print(f"R² = {r_squared:.4f}")
    
    return params, covariance


def apply_affinity_laws(Q0, H0, W0, N0, N_new):
    """
    相似律转换
    
    Parameters
    ----------
    Q0, H0, W0 : array-like, 参考转速下的流量、扬程、功率
    N0 : float, 参考转速 [rpm]
    N_new : float, 目标转速 [rpm]
    
    Returns
    -------
    Q_new, H_new, W_new : 目标转速下的预测值
    """
    ratio = N_new / N0
    Q_new = np.asarray(Q0) * ratio
    H_new = np.asarray(H0) * ratio**2
    W_new = np.asarray(W0) * ratio**3
    return Q_new, H_new, W_new
```
